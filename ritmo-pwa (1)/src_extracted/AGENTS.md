# AGENTS.md — Ritmo Architecture & Developer Guide

This file documents the architectural design, codebase layout, database integrations, and guidelines for AI agents and developers working on **Ritmo**.

## 🏛️ System Architecture Overview

Ritmo is a full-stack web application built on **TanStack Start** (SSR + Client SPA) and **Netlify Database** (PostgreSQL managed service via Drizzle ORM).

## 🔑 Key Conventions & Non-Obvious Decisions

1. **Netlify Database & Drizzle `@beta` Tag**:
   - The Netlify Database adapter only exists on the `beta` release of `drizzle-orm` and `drizzle-kit`. Never remove the `@beta` tag.
   - Migrations MUST be placed in `netlify/database/migrations/` (configured in `drizzle.config.ts`).
   - Never run `drizzle-kit migrate` or `drizzle-kit push` directly. Netlify handles migration application at deploy time automatically.
   - `server-db.ts` contains a resilient in-memory fallback store so that the application functions seamlessly during initial database provisioning or disconnected development.

2. **TanStack Start Server Handlers**:
   - Server endpoints are located in `src/routes/api.*.ts` and use `createFileRoute('/api/...')({ server: { handlers: { GET, POST, PUT, DELETE } } })`.
   - The root document in `__root.tsx` has `lang="pt-BR"` and standard `siteName` / `siteDescription` without developer placeholders.

3. **Ethical & Realistic Focus (Modo Caverna Sem Extremismos)**:
   - The user requested an original platform that promotes focus, consistency, and financial organization **without** encouraging extreme isolation, sleep deprivation, restrictive diets, or guilt over incomplete tasks.
   - Explicit medical and psychological disclaimers are present in both the Habits tab and the Finance tab.
   - Digital limits are framed as personal self-discipline commitments (no false claims of blocking OS applications).

4. **WhatsApp Business Natural Language Parser**:
   - Handles Brazilian Portuguese currency formats (e.g. `R$ 42,50`, `42.50`, `800 reais`, `60 conto`).
   - Categorizes common expenses and incomes automatically (almoço, mercado, internet, transporte, salário, etc.).
   - Explicitly rejects ambiguous inputs without amounts and asks clarifying questions instead of guessing.

5. **Affiliate & Referral Rules (30% Recurring)**:
   - Commission is strictly 30% of the net amount received on recurring billing events.
   - Prevents self-referral and enforces last-touch attribution before registration.
   - Refund and chargeback webhook events transparently reverse unearned commissions.
